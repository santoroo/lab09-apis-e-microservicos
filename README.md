# Lab 9 - APIs e Microserviços

Laboratório 9 da disciplina de Engenharia de Software, focado em construção de APIs RESTful com Flask e FastAPI, e deploy de aplicações na nuvem (Azure App Services).

## Estrutura

| Pasta | Exercício | Tecnologias |
|-------|-----------|-------------|
| [9.1](./9.1) | API Flask - Hello World e RESTful API | Flask |
| [9.2](./9.2) | API FastAPI servida com Uvicorn | FastAPI, Uvicorn |
| [9.3](./9.3) | Deploy de Hello World na nuvem | Flask, Gunicorn, Azure App Services, GitHub Actions |
| [9.4](./9.4) | Deploy de API RESTful na nuvem | Flask, Gunicorn, Azure App Services, GitHub Actions |

## Pré-requisitos

- Python 3.11+
- pip
- Conta no Azure (para os exercícios 9.3 e 9.4)
- Postman (para testar as APIs)

Cada pasta contém um README com instruções específicas para rodar e testar o exercício.
